# 자산 인출 시뮬레이터 구현 계획

이 문서는 사용자의 자산을 기반으로 인출 시뮬레이션을 제공하는 개인용 자산 관리 웹 애플리케이션의 구현 계획입니다.

## 1. 개요
*   **목표**: [Minkabu 시뮬레이션 사이트](https://itf.minkabu.jp/simulation/calculator)의 "取り崩す(인출하기)" 기능을 복제하되, 심플한 구조와 우아한 UI로 구현합니다.
*   **기술 스택**: 순수 HTML, Vanilla JS, Vanilla CSS. (프레임워크 미사용)
*   **주요 기능**:
    1.  **利回り計算 (수익률 계산)**: 목표 자산, 매월 인출액, 인출 기간을 기반으로 필요한 연간 수익률을 계산합니다.
    2.  **毎月取り崩し額を計算 (매월 인출액 계산)**: 목표 자산, 예상 수익률, 인출 기간을 기반으로 매월 인출할 수 있는 금액을 계산합니다.
    3.  **取り崩し期間を計算 (인출 기간 계산)**: 목표 자산, 예상 수익률, 매월 인출액을 기반으로 자산이 고갈될 때까지의 기간을 계산합니다.
*   **제약 조건 및 기본값**:
    *   **금융자산액 (金融資産額)**: 1억엔 ~ 3억엔 (기본값: 1억3000만엔)
    *   **매월 인출액 (毎月の取り崩し額)**: 40만엔 ~ 130만엔 (기본값: 60만엔)
    *   **인출 기간 (取り崩し期間)**: 35년 ~ 55년 (기본값: 36년)
*   **데이터 지속성**: 설정된 값은 JS의 `document.cookie`에 저장되어, 재방문 시 이전 값을 그대로 불러옵니다.

## 2. 제안된 변경 사항

### Components (Files)
#### [NEW] `index.html`
- 시뮬레이터의 뼈대가 되는 HTML 구조.
- 탭 버튼 및 각 모드에 따른 입력 폼과 결과 표시 영역 포함.

#### [NEW] `style.css`
- 고급스러운 색상 팔레트, 부드러운 애니메이션, Glassmorphism 효과.

#### [NEW] `script.js`
- DOM 조작, 탭 전환 로직, 실시간 계산 및 UI 업데이트.
- 쿠키 저장 및 불러오기 로직.

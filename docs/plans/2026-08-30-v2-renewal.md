# 자산 인출 시뮬레이터 Version 2 리뉴얼 계획 (Asset Simulator v2)

본 문서는 `tori_2026` 자산 인출 시뮬레이터를 사용자의 구체적인 요구사항에 맞추어 v2 버전으로 전면 리뉴얼하기 위한 구현 계획(Plan)입니다.

---

## 1. 리뉴얼 목표 및 배경
- **기존 v1 현황**: 단일 HTML/CSS/JS 파일 기반, 기본 4개 슬라이더(자산, 기간, 생활비, 수익률)와 3개 결과 그래프 제공.
- **v2 리뉴얼 목표**:
  1. **UI/UX 간소화 및 집중**: 불필요한 계산(수익률, 기간)을 제거하고 오직 **"매월 생활비(毎月生活費)"** 결과에 집중.
  2. **설정 항목 접기/펴기 (Collapse)**: 화면을 깔끔하게 유지하기 위해 설정 항목을 숨기고 필요할 때만 펼쳐서 수정.
  3. **목표 기반 계산 고도화**: 자산이 0이 되는 시점이 아닌, 특정 목표 연령에 **"최종 금액(最終金額)"**을 남기는 것을 목표로 역산.
  4. **모바일 가시성 극대화**: 결과 그래프의 높이를 키우고, 모바일 환경에서 쾌적하게 볼 수 있도록 차트 라이브러리 및 설정 최적화.

---

## 2. 세부 변경 사항 (User Requirements)

### A. UI/UX 변경 사항
1. **설정 항목 Collapse (접기/펴기)**
   - 파란색 배경(サマリーバー) 아래에 **"設定変更"** 버튼 추가.
   - 기본적으로 설정 항목은 접혀서 숨겨짐.
   - 버튼 클릭 시 설정 영역이 나타나며 버튼 텍스트는 **"設定隠し"**로 변경.
2. **생년월일(기준 나이) 설정 기능**
   - "60歳(2042年)から年金" 설정 영역 좌측에 생년월일을 입력할 수 있는 필드 추가.
   - 디폴트 값: `1982/7/28`
3. **"金融資産額" 슬라이더 설정 변경**
   - 범위: `1.5億円` ~ `5億円`
   - 디폴트 값: `1.5億円`
4. **"取り崩し期間" 표시 및 설정 변경**
   - 표시 형식: `79歳(35年)` 형태로 나이를 우선 표시.
   - 범위: `80歳` ~ `100歳` (목표 연령 기준)
   - 디폴트 값: `80歳`
5. **"毎月の生活費" 항목 제거 및 "最終金額" 추가**
   - 기존의 월 생활비 입력 슬라이더 제거.
   - 대체 항목: **"最終金額"** (목표 연령 시점에 남길 목표 자산)
   - 범위: `1,000万円` ~ `1億円` (1,000万円 단위 조절)
6. **"60歳(2042年)から年金" 설정 변경**
   - 체크박스 제거 (무조건 연금 수령 적용).
   - 슬라이더 추가: `20` ~ `40` (단위: 万円)
   - 디폴트 값: `20`
7. **결과 화면 정리**
   - "利回り計算", "期間" 결과 섹션 완전 제거.
   - "毎月生活費" 결과 하나만 화면에 표시.
8. **차트 가시성 강화 (모바일 최적화)**
   - 그래프 영역 높이를 기존 대비 2배로 확장하여 모바일 가시성 확보.
   - **8-1. 타이틀 요약 표시 추가**: 기준 수익률 대비 +1%, +2%, +3%, **+4%** 까지 총 4개의 비교 결과를 타이틀 영역에 표시 (예: 6%: 97万円 / 7%: 107万円 ...).
   - **8-2. 그래프 라인 단순화**: 차트에는 **기준 수익률 선 하나만** 표시하여 복잡함을 줄임.

### B. 계산 로직 변경 사항
1. **"毎月の生活費" 역산 로직 변경**
   - 입력값 제거됨에 따라, 목표 연령 도달 시 자산이 "最終金額"이 되도록 하는 매월 생활비를 계산함.
2. **연금 강제 적용**
   - 60세 이후 연금 수령 로직이 무조건 적용됨 (`usePension` 분기 제거).
3. **최종 금액(最終金額) 반영 수식**
   - 잔여 기간 동안 자산을 인출한 후 최종적으로 잔고가 `最終金額`이 되어야 함.
   - 현가(PV) 기준으로 공식을 재구성:
     $$PV = PMT \times PVAF(r, N) - Pension \times PVAF_{pension} + 最終金額 \times (1+r)^{-N}$$
   - 이를 $PMT$(매월 생활비)에 대해 정리하여 계산.

## 3. 차트 라이브러리 최적화 검토 (모바일 대응)
모바일 기기에서 세로로 긴 영역을 차지할 때 터치, 줌, 스크롤 동작이 자연스러워야 합니다.
- **옵션 1: Chart.js 유지 + `chartjs-plugin-zoom` 추가**
  - 기존 코드를 최대한 활용하면서 핀치 줌(Pinch-to-zoom)이나 패닝(Panning) 기능 추가. 반응형 옵션 세부 조정(`maintainAspectRatio: false` 적극 활용).
- **옵션 2: ApexCharts 도입 (추천)**
  - 모바일 환경에서 반응형 터치 인터랙션과 툴팁이 훨씬 부드럽고 모던한 UI를 기본 제공함.
  - v2에서는 차트가 단 1개뿐이므로 라이브러리 교체에 따른 비용이 적어 전환을 추천합니다.

---

## 4. 제안된 단계별 구현 일정
- **Phase 1**: HTML 레이아웃 개편 및 Collapse UI 적용, 불필요 영역(수익률/기간 결과) 삭제.
- **Phase 2**: 계산 엔진 리팩토링 (최종금액 수식 반영, 연금 강제화, 나이 계산 정밀화).
- **Phase 3**: 차트 고도화 (높이 2배 증가, 라인 단일화, ApexCharts 도입 혹은 Chart.js 고도화 적용).

# 자산 인출 시뮬레이터 UI/UX 개편 계획

기존 탭 구조를 제거하고 하나의 뷰(Single View)에서 모든 입력과 세 가지 결과를 동시에 볼 수 있도록 구조를 전면 개편합니다. 또한 시각적 피드백을 위해 Chart.js를 이용한 그래프를 추가합니다.

## 1. 개요
*   **통합 UI 구조**: 탭을 없애고 모든 입력 슬라이더(4개)와 결과(3개)를 세로로 배치합니다.
*   **금융자산액 단위 개편**: 1,000만엔(1000万円) 단위로 슬라이더가 움직이며, 입력 및 화면 표시는 '1.1億', '1.2億' 등의 '억(億)' 단위로 표시합니다.
*   **독립적 계산 로직**: 특정 입력값은 특정 결과에 영향을 주지 않는 구조로 계산식을 리팩토링합니다.
    *   **기간 입력** -> [기간 결과]에 미반영
    *   **인출액 입력** -> [인출액 결과]에 미반영
    *   **수익률 입력** -> [수익률 결과]에 미반영
*   **결과 시각화 (그래프 추가)**: 결과별로 자산 잔액의 연도별 변동 추이를 보여주는 라인 차트를 제공합니다. (Chart.js CDN 사용)

## 2. 제안된 변경 사항

### [MODIFY] `index.html`
*   Chart.js 라이브러리를 `<head>`에 추가: `<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>`
*   탭 네비게이션을 제거.
*   입력 영역(4개: 자산, 기간, 인출액, 수익률)을 수직으로 배치.
*   결과 영역(3개)과 그 내부에 `<canvas>` 태그를 배치하여 차트를 렌더링할 공간 확보.

### [MODIFY] `style.css`
*   결과 컨테이너를 Grid 또는 Flex로 나란히 또는 세로로 보기 좋게 배치.
*   캔버스(그래프) 크기와 카드 레이아웃 정리.
*   입력 텍스트 박스의 크기와 단위를 '億'으로 조정하는 CSS 반영.

### [MODIFY] `script.js`
*   **입력/표시 단위 변경**: 자산(Asset) 표기를 '억' 단위로 포맷팅.
*   **전역 상태 계산**: 세 가지 결과를 각각 필요한 입력값만 취해 독립적으로 계산.
*   **차트 렌더링 함수 (`drawChart`)**:
    *   각 결과(필요 수익률 적용 시, 매월 인출액 적용 시, 인출 기간 적용 시)에 따른 자산 잔액 변화를 계산해 Chart.js 업데이트.

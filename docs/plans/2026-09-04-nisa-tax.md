# NISA(비과세)枠額 설정 및 세금 공제 로직 추가

현재 자산 운용 시뮬레이션에서 毎月生活費(매월 생활비)를 계산할 때, NISA 비과세 금액을 반영하여 20% 세금을 공제하는 로직을 추가합니다.

## User Review Required

> [!IMPORTANT]  
> **세금 공제 방식 확인**  
> 현재 생활비 계산에는 원금 인출도 포함되어 있습니다. 일본의 실제 세제에서는 **이익(수익)에 대해서만 20.315%의 세금**이 부과되지만, 요청하신 계산 로직은 **"전체 월 생활비(원금+수익)에서 과세 대상 비율만큼 20%를 차감"**하는 방식입니다.  
> *계산식:*  
> 비과세 비율 = `Min(총자산, NISA설정액) / 총자산`  
> 과세 비율 = `Max(0, 총자산 - NISA설정액) / 총자산`  
> 세후 생활비 = `(세전 생활비 * 비과세 비율) + (세전 생활비 * 과세 비율 * 0.8)`  
> 이 방식대로 구현을 진행해도 좋을지 확인 부탁드립니다.

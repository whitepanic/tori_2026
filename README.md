# 資産運用シミュレーション (Asset Withdrawal Simulation Dashboard)

純粋なHTML、CSS、JavaScriptのみで構築された、シンプルかつ強力な個人用資産管理シミュレーターです。保有する金融資産を取り崩しながら運用した場合の推移を、さまざまなシナリオ（利回り・毎月の取り崩し額・取り崩し期間）に基づいて計算し、グラフで視覚化します。

## 主な機能 (Features)

1. **3つのメインシミュレーション機能**
   - **利回り計算 (Required Yield):** 指定した期間、指定した額を取り崩すために必要な年利を逆算します（二分探索アルゴリズムによる高精度計算）。
   - **毎月取り崩し額 (Monthly Withdrawal):** 現在の資産と利回りから、指定期間にわたって毎月いくら取り崩せるかを計算します。
   - **取り崩し期間 (Withdrawal Period):** 現在の資産と利回りで、毎月一定額を取り崩した場合、何年間資産が保つかを計算します。

2. **動的で直感的なUI/UX**
   - **即時反映:** スライダー（Range Input）を動かすだけで、即座にすべての計算とグラフが更新されます。
   - **サマリーバー:** 現在の設定値が一目でわかる要約バーを最上部に配置。
   - **複数シナリオの比較:** 「毎月取り崩し額」と「取り崩し期間」のグラフでは、基準となる利回りに対して **+1%、+2%、+3%** のシミュレーション線を自動的に追加表示し、リスクとリターンの比較を容易にします。
   - **動的なX軸ラベル:** グラフの描画期間（年数）に応じて、X軸の目盛り間隔（1年、2年、3年、5年、6年単位）を自動で最適化します。
   - **年齢表示のサポート:** 「35年（79歳）」のように、期間と年齢をリンクさせた表示に対応。

3. **レスポンシブデザイン (Smartphone Ready)**
   - 画面幅が 460px 以下のデバイス向けに、パディングの自動縮小、Y軸の「億」単位の省略、サマリーバーの折り返し（改行）処理を行い、スマートフォンの小さな画面でもグラフが最大限に読みやすくなるよう最適化されています。

4. **設定の自動保存 (Cookie)**
   - 設定した「金融資産額」「毎月の取り崩し額」「取り崩し期間」「利回り」はブラウザのCookieに自動で保存され、次回アクセス時にも前回の状態が復元されます。

## 使用技術 (Tech Stack)

- **フロントエンド:** Vanilla HTML5, CSS3, ES6 JavaScript
- **グラフ描画ライブラリ:** [Chart.js](https://www.chartjs.org/) (CDN経由で読み込み)
- **ビルドツール:** なし（ローカル環境で `index.html` を開くだけですぐに動作します）

## インストールと実行 (How to Run)

依存関係のインストールやサーバーの構築は不要です。

1. リポジトリのファイルをダウンロードします。
2. フォルダ内の `index.html` をお好みのブラウザ（Chrome, Safari, Edge など）で開くだけで、すぐにシミュレーターを使用できます。
